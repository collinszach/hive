All mock API responses — realistic fake data for every endpoint the app calls. Named "Alex Rivera", plausible amounts, no real info.

scripts/take-screenshots.js

Playwright script. Launches browser, installs route interceptors, navigates each page, waits for render, saves PNG.

How it works

  1. Script intercepts /api/auth/me → returns fake user, bypassing login redirect
  2. All /api/* calls are routed to fixture data (no real backend traffic)
  3. For each page: navigate → wait for network idle → wait 500ms for animations → screenshot
  4. Screenshots saved to screenshots/ with descriptive filenames
